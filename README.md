# 한수 — 쉬운 바둑 (MVP)

입문 ~ 1급을 위한 바둑 학습 웹앱. `driving-license-app`과 같은 토스 톤 UI/UX, Capacitor 웹뷰로 Android · iOS · 웹 배포.

## 실행

```bash
npm install
npm run dev          # http://localhost:43212
npm run build
npm run ios          # Capacitor sync + Xcode
npm run android
```

## MVP 플로우

1. **온보딩** — 현재 급수 선택 → 목표 급수 → 목표 날짜  
2. **홈** — 목표 D-Day, 트랙 진도, 다음 레슨 CTA  
3. **배우기** — 급수 트랙(씨앗 5줄 → 숲 19줄) 챕터·레슨  
4. **레슨** — 설명 + 인터랙티브 바둑판(정답 수 두기)  
5. **경로** — 현재/목표 급수 의미, 트랙 맵, 초기화  

## 급수 → 판 크기

| 트랙 | 판 | 대상 |
|------|-----|------|
| 씨앗 | 5줄 | 입문 · 30급 |
| 새싹 | 7줄 | 25 · 20급 |
| 잎새 | 9줄 | 15급 |
| 나무 | 13줄 | 10 · 7급 |
| 숲 | 19줄 | 5 · 3 · 1급 |

10급 설명 예: *19줄 바둑판에서 바둑을 끝낼 수 있을 정도의 실력*
